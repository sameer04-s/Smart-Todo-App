# 📝 To-Do App

A modern, responsive, and user-friendly To-Do List application built using **HTML, CSS, and JavaScript**. It helps users organize daily tasks, track productivity, and manage completed activities with a clean and interactive interface.

## 🚀 Features

- **Add Tasks:** Quickly add new tasks to your list.
- **Edit Tasks:** Update existing tasks whenever needed.
- **Delete Tasks:** Remove tasks you no longer need.
- **Complete Tasks:** Mark tasks as completed with a checkbox.
- **Task Statistics:** Track total, active, and completed tasks.
- **Progress Tracking:** Visual progress bar showing task completion percentage.
- **Search Tasks:** Find tasks instantly using the search feature.
- **Filter Tasks:** View All, Active, or Completed tasks.
- **Clear Completed:** Remove all completed tasks at once.
- **Dark & Light Mode:** Switch between themes.
- **Local Storage:** Automatically saves tasks and theme preferences, even after refreshing the page.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Application structure |
| CSS3 | Styling, animations, and responsive design |
| JavaScript | Application functionality |
| Local Storage | Persistent task storage |

## 💻 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/sameer04-s/Todo-App.git
```

**2. Navigate to the project folder**

```bash
cd Todo-App
```

**3. Open the project**

Open `index.html` in your browser or use the Live Server extension in VS Code.
